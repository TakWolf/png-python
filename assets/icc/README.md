# Official ICC profiles

These unmodified ICC profiles come from the International Color Consortium's
[sRGB profiles page](https://registry.color.org/rgb-registry/srgbprofiles).
Exact download URLs, lengths, retrieval dates and SHA-256 digests are recorded in
`SOURCE.json`. They exercise ICC v2 and v4 structural checks and PNG embedding;
they are test assets, not runtime dependencies.

- `sRGB2014.icc`: ICC v2, 3024 bytes, revised by ICC in February 2015.
- `sRGB_v4_ICC_preference.icc`: ICC v4.2 preference profile, 60960 bytes.

The original copyright and identification tags are retained. See `LICENSE.txt`
for the corresponding upstream terms. Deliberately damaged in-memory test
vectors are not distributed as original ICC profiles.
